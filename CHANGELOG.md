# Changelog

All notable changes to CryptoTrace AI will be documented in this file.

## [1.0.0] - 2026-09-02

### Added
- Core `src/cryptotrace/` modular package architecture.
- Multi-format ingestion parsers (CSV, JSON, XML) with schema validation.
- GeoIP & ASN enrichment engine with local caching and offline fallback.
- Inductive GraphSAGE GNN and NetworkX heterogeneous graph builder.
- Supervised XGBoost classifier with strict temporal train/val/test splitting.
- Unsupervised Isolation Forest anomaly scoring engine.
- SHAP TreeExplainer decision decomposition and machine-readable evidence packages.
- Configurable multi-modal composite risk scoring engine.
- Interactive multi-page Streamlit forensic intelligence dashboard.
- Pytest unit and integration test suite with fixture datasets.
- CI/CD GitHub workflows for automated testing and code linting.

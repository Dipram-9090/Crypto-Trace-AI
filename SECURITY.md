# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within CryptoTrace AI, please do NOT create a public issue.

Instead, please send a responsible disclosure email to the maintainers at `security@cryptotrace.ai` or submit a private security report through GitHub.

We will review, patch, and publish a vulnerability advisory within 48 hours.

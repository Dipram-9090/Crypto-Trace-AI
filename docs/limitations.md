# ⚠️ Limitations & Ethical Disclaimers

### 1. Approximate IP Geolocation
IP addresses are contextual broadcast points, often corresponding to VPNs, proxies, public Wi-Fi, or cloud relays. IP geolocation is approximate and **does not identify individual human persons**.

### 2. Synthetic Network Layer Correlation
While blockchain transactions reflect realistic on-chain graph properties, the network-layer metadata in this prototype is synthetically correlated to satisfy hackathon forensic problem statements without conducting non-consensual network interception.

### 3. False Positives & Legitimate High-Volume Entities
Legitimate crypto exchanges and high-volume merchant payment processors also exhibit high fan-out and transaction velocity. CryptoTrace AI scores entities for **investigative prioritization** rather than delivering definitive criminal determinations.

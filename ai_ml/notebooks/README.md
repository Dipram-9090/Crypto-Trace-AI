# AI/ML Research & Experimentation Notebooks

This directory contains research workflows, GNN graph topology experiments, anomaly detection studies, and SHAP explainability notebooks:

1. `01_data_exploration.ipynb` - Statistical distributions, token flows, and dataset loader benchmarks.
2. `02_feature_engineering.ipynb` - Network topological metrics, velocity features, and temporal cyclic embeddings.
3. `03_xgboost_fraud_classifier.ipynb` - Supervised classification training and hyperparameter optimization.
4. `04_anomaly_detection_autoencoders.ipynb` - Isolation Forest, One-Class SVM, and Deep Autoencoder reconstruction loss.
5. `05_gnn_graphsage_experiments.ipynb` - PyTorch Geometric GraphSAGE multi-hop node and edge classification.
6. `06_shap_lime_explainability.ipynb` - Interpretability waterfalls, force plots, and natural language SAR reasoning.
